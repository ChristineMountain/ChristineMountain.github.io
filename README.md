# Christine Le — Personal Website

🌐 **Live site:** [christinemountain.github.io](https://christinemountain.github.io/)

My personal portfolio site — a soft, scrapbook-inspired take on a resume, built with plain HTML, CSS, and JavaScript (no frameworks, no build step).

## About the design

Cream and pastel color palette (dusty pink, sage, lavender) with a mix of an elegant serif for headings, a handwritten script for little accent notes, and a clean rounded sans-serif for body text. Hand-drawn SVG doodles, washi tape, and note-card shapes are layered throughout for a personal, handmade feel, while the content itself — education, experience, projects, and leadership — is pulled straight from my resume.

## Built with

- HTML5 / CSS3 / vanilla JavaScript
- [Google Fonts](https://fonts.google.com/): Cormorant Garamond, Caveat, Nunito
- Hosted for free on [GitHub Pages](https://pages.github.com/)

## Running it locally

No build step required — just clone and open the file:

```bash
git clone https://github.com/ChristineMountain/ChristineMountain.github.io.git
cd ChristineMountain.github.io
```

Then open `index.html` in your browser.
